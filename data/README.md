# Driving Route Planner Dataset

This folder contains the datasets used by the
Driving Route Planner application.

## Planned Files

- texas_cities.csv
  Texas city names and population information.

- texas_roads.csv
  Road connections and driving distances.

## Routing

The routing module will use these datasets
to construct a weighted graph and calculate
shortest paths using Dijkstra's algorithm.
